Сервисы, которые нужно покрыть трейсингом: Shop API, CRM API, MES API.

Данные, которые должно попадать в трейсинг:

- Trace Id
- Span Id
- Номер заказа
- Клиент
- Статус заказа
- URL
- Метод запроса
- Версия сервиса
- ID файла заказа
- Оператор

# Мотивация

- Видно на каком статусе остановился заказ и как его продолжить, чтобы не потерять и не отказывать клиенту
- Более дешевый подход, чем накопление логов
- Выявление медленных сервисы и выполнить оптимизацию или масштабирование
- Быстрое обнаружение и понимание проблемы в системе
- Сокращение времени на отладку позволяет направить его на разработку нового функционала
- В конечном итоге удовлетворенность клиентов

# Предлагаемое решение

Трейсинг внедряется с помощью платформы OpenTelemetry и системы Jaeger.

1. Установить Jaeger-collector, базу данных Jaeger, Jaeger-query и Jaeger-ui
2. На хосты с сервисами Shop API, CRM API, MES API нужно поставить Jaeger-agent.
3. Внедрить в сервисы Shop API, CRM API, MES API реализацию opentracing и направить данные в jaeger-agent.

# Компромиссы

- Не стоит тратить ресурсы команды на внедрение трейсинга, если и так ясно, что нужно исправлять на основе тестирования
- Для небольших проектов трейсинг может быть излишним

# Аспекты безопасности

- Авторизация пользователей, просмотр трейсинга в окружении production разрешена только Администраторам
- В трейсинг не должны попадать персональные данные клиентов
- Можно использовать шифрование данных
